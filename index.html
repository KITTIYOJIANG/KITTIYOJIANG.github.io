智能车人工智能视觉组虚拟推箱子规划

一句话成果

面向第二十一届全国大学生智能汽车竞赛人工智能视觉组，我整理并实现了一条从 OpenMV 屏幕图像调参、16x12 推箱子地图建模、BFS/A* 路径规划 到 车端 JSON 命令输出 的原型链路，用于把虚拟推箱子任务拆成真实小车可以执行的 move_to、align_to_box、push_box 指令。

项目定位

  • 方向: 机器视觉 / 智能车 / 路径规划 / 嵌入式系统
  • 工具: Python、OpenMV、SmartCar VR V1.2、BFS、A*、JSON command interface
  • 能力展示: 比赛规则拆解、视觉调参、地图抽象、搜索规划、指令编译、测试验证
  • 当前状态: 已完成文本地图模拟器、规划器、命令消费者、OpenMV 暗屏调参脚本和官方调试环境接入记录

STM32F103 TinyCNN 手写数字识别

一句话成果

在资源受限的 STM32F103C8T6 (Cortex-M3, 72MHz, 无 FPU) 上，我用纯 C 实现了 TinyCNN 的前向推理链路，让单片机可以完成手写数字识别。

核心指标

  • 硬件: STM32F103C8T6 + USB 转 TTL + Python 手写数字画板
  • 模型: PyTorch 训练，2 层卷积 + 1 层全连接
  • 推理耗时: 约 220ms
  • 准确率: MNIST 测试集 >98%
  • 资源占用: Flash < 20KB，RAM < 5KB
