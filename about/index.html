关于我 (About Me)

👋 你好，我是吴则勋 (GOH ZE XUAN)。

我来自马来西亚，目前就读于 北京理工大学自动化专业。我的兴趣集中在机器人控制、嵌入式系统、机器视觉和 TinyML：从底层硬件调试，到算法部署，再到把系统真正跑起来，我最享受的是让代码和机械产生可靠互动的过程。

我正在寻找 2026 暑期实习机会，方向偏自动化、机器人、控制、嵌入式系统或相关工程岗位，期望 Base 北京，也欢迎外企和国际化团队。

技术栈 (Tech Stack)

  • 嵌入式与底层驱动: STM32 外设控制、串口通信、资源受限设备上的 C 语言开发。
  • 机器人与仿真: ROS/ROS2 学习与实践，Webots 仿真环境，移动机器人导航与控制。
  • 控制与算法: PID 控制、TinyML 推理部署、Python 数据处理与上位机工具。
  • 机械设计: SolidWorks 建模与结构设计，正在推进外骨骼机械臂相关实践。
  • 工业系统: SmartLine-IoT 工业物联网项目经验，关注设备数据采集、状态监控与告警链路。

作品集重点

  • STM32F103 TinyCNN 手写数字识别：在 Cortex-M3、无 FPU 的低资源单片机上用纯 C 手写 CNN 推理，推理耗时约 220ms。
  • ROS2 Nav2 移动机器人导航仿真：展示机器人仿真、Nav2 运行证据、导航流程和控制模块拆解；代码见 ros2_nav。
  • 智能车人工智能视觉组虚拟推箱子规划：展示 OpenMV 屏幕调参、16x12 地图建模、BFS/A* 搜索、动作回放验证和车端 JSON 命令接口。
  • SmartLine-IoT 工业物联网产线监测系统：展示工业设备数据采集、状态看板和告警架构设计；代码见 iot_project。
