作品集 Portfolio

这里集中展示 3 个最能代表我工程能力的项目：嵌入式 AI、机器人导航、工业物联网。每个项目都尽量提供可验证材料，包括图片、视频、代码、指标或演示链接。

1. STM32F103 TinyCNN 手写数字识别

  • 方向: 嵌入式 AI / TinyML
  • 关键词: STM32F103C8T6、Cortex-M3、纯 C CNN、UART、Python 上位机
  • 核心结果: 在无 FPU 的 STM32F103 上完成手写数字 CNN 推理，单次推理约 220ms，MNIST 测试集准确率 >98%。
  • 项目页面: 查看详情
  • 公开状态: 已提供 demo、指标和核心代码片段；完整工程暂未公开

2. Webots + ROS2 移动机器人导航仿真

  • 方向: 机器人导航与控制
  • 关键词: ROS2 Humble、Nav2、TurtleBot3、TF、RViz、SLAM/Webots
  • 核心结果: 整理 ROS2/Nav2 本地运行证据，包含 /navigate_to_pose SUCCEEDED、0 次 recovery、6753 条 ROS bag 消息和 RViz/SLAM 录屏。
  • 项目页面: 查看详情
  • GitHub: KITTIYOJIANG/ros2_nav

3. SmartLine-IoT 工业物联网产线状态监测系统

  • 方向: 工业物联网 / 自动化系统
  • 关键词: 设备状态、传感器数据、异常告警、Dashboard、数据链路
  • 核心结果: 用系统设计方式拆解设备层、采集层、服务层和展示层，展示工业自动化系统中“可观测、可追踪、可维护”的设计思路。
  • 项目页面: 查看详情
  • Demo: 小红书笔记，项目页内已嵌入 Grafana 看板录屏
  • GitHub: KITTIYOJIANG/iot_project
