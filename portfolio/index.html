智能车人工智能视觉组：视觉识别、地图规划与车端控制

一句话成果

从 FOMO 轻量视觉模型、OpenART/OpenMV 板端识别、16×12 地图定位，到 BFS/A* 规划与 RT1064 通信的智能车工程链路。

项目背景

项目面向第二十一届全国大学生智能汽车竞赛人工智能视觉组。任务不是单点算法，而是需要把角色/数字识别、屏幕视觉、地图抽象、路径规划和车端动作接口串成一条可调试链路。

我解决了什么问题

我把比赛任务拆成可验证的工程边界：视觉侧输出类别、地图和姿态，规划侧生成动作序列，通信侧连接 OpenART/OpenMV 与 RT1064；同时保留模型评估、实机录屏和回放测试，方便定位误识别与控制接口问题。

技术栈

OpenART / OpenMV / TensorFlow Lite / FOMO / Python / BFS / A* / RT1064 / UART / WiFi

核心证据

FOMO 评估包含 1,151 条样本，验证集分类准确率 93.59%、中心定位准确率 100%；项目页同时展示角色识别、数字识别、左目地图跟踪视频，以及 16 张规划测试地图和通信联调证据。

当前状态

已完成角色/数字识别、地图定位与角度跟踪、FOMO 模型评估、规划器、命令消费者及 UART/WiFi 联调记录；完整闭环仍在继续集成与场地验证。

ROS2 Nav2 移动机器人导航仿真

一句话成果

基于 ROS2 Humble、Nav2、TurtleBot3、Gazebo/Webots 的移动机器人导航验证流程。

项目背景

移动机器人导航项目容易停留在单张 RViz 截图。我希望把仿真环境、TF 链路、Nav2 action、topic、rosbag 和视频整理成一套能被复查的工程证据链。

我解决了什么问题

我搭建并整理 Gazebo/Webots 仿真环境，拆分 /scan、/odom、/tf、/plan、/cmd_vel 等关键数据流，并用 action 状态、rosbag 消息数量和运行视频证明导航流程真实跑通。

技术栈

ROS2 Humble / Nav2 / TurtleBot3 / Gazebo / Webots / RViz / SLAM Toolbox / rosbag

核心证据

/navigate_to_pose 最终状态 SUCCEEDED，0 次 recovery，约 69.6s rosbag，6753 条消息；项目页包含主展示视频、TF 链路图、Nav2 运行证据图和关键 topic 统计。

当前状态

已完成作品集展示页、1 分钟内主展示视频、真实 Gazebo + Nav2 action 成功日志、ROS bag 与量化指标整理。后续可继续补自动化复现实验脚本。

STM32F103 TinyCNN 手写数字识别

一句话成果

在 STM32F103C8T6 上用纯 C 实现 TinyCNN 前向推理链路。

项目背景

STM32F103C8T6 资源有限、无 FPU，不能直接依赖高级 AI 部署库。这个项目用低资源单片机验证 TinyML 推理链路，重点展示嵌入式 AI 的工程落地能力。

我解决了什么问题

我用纯 C 实现 CNN 前向推理，把模型参数、输入预处理、推理计算和串口输出整理成能在资源受限设备上运行的闭环，并针对栈空间、手写输入分布差异等问题做了工程处理。

技术栈

STM32F103C8T6 / C / TinyML / CNN / UART / Embedded AI / MNIST

核心证据

单次推理约 220ms，MNIST 测试集准确率大于 98%，Flash 小于 20KB，RAM 小于 5KB；项目页保留核心代码片段和公开状态说明。

当前状态

项目页已整理 Demo、指标、系统架构、难点与核心代码。独立 GitHub 仓库暂未公开，后续需要在确认版权、工程结构和说明文档后再发布。

SmartLine-IoT 工业物联网产线状态监测系统

一句话成果

面向自动化产线的数据采集、状态监测、异常告警和看板展示系统设计。

项目背景

工业自动化项目需要把设备数据、状态判断、异常告警和可视化看板连接起来。这个项目用于展示从设备层到展示层的工业物联网系统设计能力。

我解决了什么问题

我整理了设备层、采集层、服务层和展示层的数据链路，把 DHT11 环境监控、MQTT/数据上传、Grafana 看板和异常告警思路串成一个可演示的产线状态监测方案。

技术栈

IIoT / MQTT / STM32 / Sensor Data / Dashboard / Grafana / Monitoring / Automation

核心证据

系统架构图、Grafana 看板录屏、小红书演示链接和代码仓库；项目页内嵌本地 Grafana 录屏，展示 DHT11 环境监控曲线、查询配置和 Dashboard 面板编辑过程。

当前状态

已补充系统架构图、Grafana 看板录屏、小红书演示链接和代码仓库。后续可继续补一页“部署/复现说明”，让项目更适合作为技术服务案例。
