ROS2 Nav2 移动机器人导航仿真

一句话成果

基于 ROS2 Humble、Nav2、TurtleBot3 和 Gazebo/Webots 仿真，我搭建并整理了一套移动机器人导航验证流程，用于展示机器人建模、传感器数据流、TF 链路、路径规划和速度控制输出。

项目定位

  • 方向: 机器人导航与控制
  • 工具: ROS2 Humble、Nav2、TurtleBot3、Gazebo/Webots、RViz、SLAM Toolbox
  • 能力展示: 仿真环境搭建、SLAM/RViz 观察、Nav2 action 验证、TF/Topic/rosbag 证据整理
  • GitHub: KITTIYOJIANG/ros2_nav
  • 当前状态: 已补充 1 分钟内主展示视频、真实 Gazebo + Nav2 action 成功日志、ROS bag 与量化指标

快速入口

  • 代码仓库: github.com/KITTIYOJIANG/ros2_nav
  • 项目总览: 作品集 Portfolio
  • 重点证据: /navigate_to_pose SUCCEEDED、0 次 recovery、6753 条 ROS bag 消息、Gazebo/Nav2 运行视频、TF 与 topic 证据图

主展示视频

这版视频把原始录屏整理成一条更适合作品集的证据链：Webots/Gazebo 场景、RViz/SLAM 建图、Nav2 路径规划、调参后运行结果，以及最终 Gazebo/Nav2 rosbag 渲染。最终片段中，蓝色机器人位姿来自 /odom，绿色点来自 /scan，紫色路径来自 Nav2 /plan，红色轨迹来自实际行驶里程计，速度条来自 /cmd_vel。

我的职责

  • 搭建 Webots/Gazebo 仿真环境，配置机器人模型、传感器和运动约束。
  • 整理 ROS2 launch、Nav2 参数、地图、RViz 配置和仿真运行流程。
  • 拆分导航链路中的关键输入输出，包括 /scan、/odom、/tf、/plan 和 /cmd_vel。
  • 用截图、TF 树、topic/node 列表和 ROS bag 记录本地运行证据，便于复现与验收。

系统拆解

  1. 仿真环境: Webots/Gazebo 负责机器人模型、场景、传感器反馈和碰撞环境。
  2. 数据接口: ROS2 topic/service/action 用于传递传感器状态、TF、导航目标和控制指令。
  3. 定位与规划: AMCL、map server、planner server 和 controller server 组成核心导航链路。
  4. 验证方法: 通过 lifecycle 状态、topic 输出、TF 结构、路径规划结果和速度命令验证系统是否跑通。

工程整理

项目仓库已经把 Webots/SLAM 截图、Nav2 运行结果、rosbag、TF 树和技术报告统一到 README 与 demo/、docs/ 目录中。页面这里只保留对招聘方最有用的证据摘要，完整材料见 ros2_nav 仓库。

这个项目想证明什么

招聘方看这个项目时，重点不是“只放一张仿真截图”，而是能看到我在机器人系统里拆问题的方式：环境、数据、定位、规划、控制、验证，每一层都能单独定位问题，也能组合成完整链路。
