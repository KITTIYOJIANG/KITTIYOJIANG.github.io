硬核！纯C语言在STM32F103上从零手写卷积神经网络 (TinyCNN)

项目简介 (Project Overview)

在资源极度受限的 STM32F103C8T6 (Cortex-M3, 72MHz, 无FPU) 上，我成功部署了一个手写数字识别系统。

不同于使用 ST 官方的 X-CUBE-AI（F103 不支持）或 MicroPython，本项目从零开始用纯 C 语言实现了卷积神经网络 (CNN) 的底层算子（卷积、池化、全连接），并在单片机上完成了端到端的推理。

核心参数 (Key Specs)

  • 硬件: STM32F103C8T6 + USB转TTL + 自制 Python 画板
  • 模型: PyTorch 训练的 2层卷积 + 1层全连接 TinyCNN
  • 性能: 推理耗时 220ms / 准确率 >98%
  • 资源: Flash占用 <20KB, RAM占用 <5KB (手动优化内存管理)

系统架构 (Architecture)

  1. 模型训练 (Training): 使用 PyTorch 在 PC 端训练 MNIST 数据集，并将权重导出为 C 语言头文件 (weights.h)。
  2. 数据通信 (Communication): Python 上位机通过串口 (UART, 115200 baud) 将 28x28 像素的二值化图像数据 (784 bytes) 发送给 MCU。
  3. 推理引擎 (Inference Engine): 在 MCU 上运行手写的 C 语言推理代码，包含 Conv2d, MaxPool2d, ReLU, FullyConnected 等算子。

遇到的挑战与解决方案 (The “Hard” Parts)

1. F103 不支持 AI 库

问题: STM32F103 是老款 Cortex-M3 内核，不支持 ST 的 X-CUBE-AI 扩展包。
解决: 手写算子。我复现了深度学习的前向传播过程。为了节省内存，我没有使用动态内存分配 (malloc)，而是使用了静态全局缓冲 (Static Buffers) 并复用内存块。

2. 栈溢出 (Stack Overflow)

问题: 神经网络推理过程中产生的临时数组会导致 1KB 的默认栈空间瞬间爆炸，程序进入 HardFault。
解决: 修改启动文件 startup_stm32f103xb.s，将栈空间 (Stack_Size) 调整为 **4KB (0x1000)**，确保了系统的稳定性。

3. 通信与数据预处理

问题: 简单的图像缩放会导致识别率低。
解决: 在 Python 端增加了自动居中 (Auto-centering) 和 二值化锐化 算法，模拟 MNIST 数据集的格式，显著提升了“潦草字迹”的识别率。

核心代码片段 (Code Showcase)

这是我手写的卷积层实现，针对内存进行了优化：

#include <algorithm> // for std::max

#include <algorithm>

void Conv3x3_ReLU_MaxPool_Optimized(
    const float* __restrict__ input, int in_ch, int in_h, int in_w,
    float* __restrict__ output, int out_ch,
    const float* __restrict__ weights, const float* bias) 
{
    const int in_hw = in_h * in_w;   // 预计算输入通道大小
    const int out_h = in_h / 2;
    const int out_w = in_w / 2;

    for (int oc = 0; oc < out_ch; ++oc) {
        // 重点 1: 提取当前输出通道的权重和偏置，避免在内层循环重复计算指针
        const float* oc_weights = weights + oc * in_ch * 9;
        const float b = bias[oc];
        float* oc_output = output + oc * (out_h * out_w);

        for (int oh = 0; oh < out_h; ++oh) {
            for (int ow = 0; ow < out_w; ++ow) {
                
                float max_val = -1e10f; 

                // 重点 2: 遍历 2x2 池化窗口。注意池化步长通常等于窗口大小（Stride=2）
                for (int ph = 0; ph < 2; ++ph) {
                    for (int pw = 0; pw < 2; ++pw) {
                        int cur_r = oh * 2 + ph;
                        int cur_c = ow * 2 + pw;

                        float conv_sum = b; // 重点 3: 直接用 bias 初始化，少做一次加法

                        // 3x3 卷积计算
                        for (int ic = 0; ic < in_ch; ++ic) {
                            const float* ic_input = input + ic * in_hw;
                            const float* k_ptr = oc_weights + ic * 9;

                            for (int k = 0; k < 9; ++k) {
                                int img_r = cur_r + (k / 3) - 1; // Padding=1 的逻辑
                                int img_c = cur_c + (k % 3) - 1;

                                // 边界检查
                                if (img_r >= 0 && img_r < in_h && img_c >= 0 && img_c < in_w) {
                                    conv_sum += ic_input[img_r * in_w + img_c] * k_ptr[k];
                                }
                            }
                        }
                        
                        // 重点 4: 融合 ReLU 与 MaxPool，减少内存读写次数
                        float relu_out = std::max(0.0f, conv_sum);
                        if (relu_out > max_val) max_val = relu_out;
                    }
                }
                oc_output[oh * out_w + ow] = max_val;
            }
        }
    }
}
