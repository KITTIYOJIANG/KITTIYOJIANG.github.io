SmartLine-IoT 工业物联网产线状态监测系统

一句话成果

SmartLine-IoT 是一个面向自动化产线的工业物联网项目，用于展示设备数据采集、状态监测、异常告警和看板展示的系统设计能力。

项目定位

  • 方向: 工业物联网与自动化系统
  • 关注点: 设备状态、传感器数据、异常告警、可视化看板
  • 能力展示: 系统架构设计、数据链路拆解、工程化表达
  • 当前状态: 已补充系统架构整理图、Grafana 看板录屏和外部演示链接；后续补充代码和报告

系统架构图

这张图是根据项目设计整理出的架构图，用来说明设备层、采集层、服务层和展示层之间的数据流，不是实际运行截图。

我的职责

  • 梳理产线设备侧、数据采集侧和上位机看板之间的模块边界。
  • 设计设备状态字段，包括运行、停止、异常、维护等基础状态。
  • 规划告警链路，让异常能够从设备侧传到看板侧，并保留后续扩展空间。
  • 整理工业系统中“可观测、可追踪、可维护”的设计思路。

系统架构

  1. 设备层: 传感器、执行器、控制器或 PLC 采集现场状态。
  2. 采集层: 将设备数据转换为统一字段，准备上传或本地缓存。
  3. 服务层: 处理设备状态、告警事件和历史记录。
  4. 展示层: 通过 Dashboard 展示产线状态、设备健康度和异常列表。

已补充材料与待补充证据

  • 已补充: 系统架构整理图、Grafana 看板录屏、小红书演示链接。
  • 代码: 后续补充数据采集、接口或 Dashboard 仓库链接。
  • 报告: 后续补充更完整的模块说明。
  • 指标: 补充刷新频率、告警延迟、设备数量等量化指标。

这个项目想证明什么

这个项目适合用来展示我对工业自动化系统的整体理解：不仅关注单个功能能不能跑，也关注数据如何被采集、状态如何被解释、异常如何被发现，以及后续如何维护。
