FOC 控制数学核心：Clarke/Park 变换与 PID SIL 验证

一句话成果

我整理并验证了一个面向电机控制的 FOC 数学核心，用纯 C 实现 Clarke 变换、Park 变换、逆 Park 变换和带抗积分饱和的 PID 控制器，并用软件在环方式验证关键输出。

项目定位

  • 方向: 电机控制 / 嵌入式控制 / 机器人底层执行
  • 工具: C99、float、Clarke/Park、PID、SIL 验证
  • GitHub 相关仓库: KITTIYOJIANG/Embodied_FOC
  • 能力展示: 底层数学实现、零动态内存、控制周期思维、SIL 验证
  • 当前状态: 本地 C99 SIL 版本已验证核心变换与 PID 前 10 步输出；公开仓库继续向实时控制库方向整理

系统总览

FOC 的核心价值是把三相电流/电压转换到旋转坐标系下控制，让电机控制问题从三相波形变成更容易调节的 d/q 轴问题。这个项目先把最小数学核心写清楚，并用软件在环方式验证输出是否符合预期。

已实现内容

模块 当前结果
坐标结构 foc_uvw_t、foc_ab_t、foc_dq_t
Clarke 变换 三相 UVW -> alpha/beta
Park 变换 静止坐标系 alpha/beta -> d/q
逆 Park 变换 d/q -> alpha/beta，为电压输出做准备
PID 控制器 支持 Kp/Ki/Kd、积分限幅、输出限幅和状态 reset
内存策略 静态结构体与函数接口，不依赖动态内存分配
SIL 验证 用平衡三相输入和 1kHz 控制周期做软件在环测试

代码边界

这个项目刻意保持小而硬：

  • 不做 GUI。
  • 不依赖第三方控制库。
  • 不在核心函数里动态分配内存。
  • 不把硬件 IO 和数学核心混在一起。

这样做的好处是后续可以把同一套数学函数迁移到 STM32、机器人关节控制或更复杂的实时控制框架里。

我的职责

  • 手写 FOC 需要的基础坐标变换函数，并保留清晰的 C 接口。
  • 设计 PID 控制器结构体，加入积分限幅和输出限幅，避免控制量失控。
  • 写软件在环验证程序，用可解释输入检查 Clarke/Park 输出和 PID 响应。
  • 将底层控制项目从“能跑的代码”整理成可以被作品集说明的模块边界。

这个项目想证明什么

这个项目展示的是我对机器人和自动化底层控制的关注：作品集不只放上层 AI 和可视化，也保留电机控制、坐标变换、实时循环和嵌入式约束这些更底层的工程能力。对于控制、机器人和嵌入式岗位，这类小项目的可信度很高。
