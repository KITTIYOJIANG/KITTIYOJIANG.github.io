STM32F103 TinyCNN 手写数字识别

一句话成果

在资源受限的 STM32F103C8T6 (Cortex-M3, 72MHz, 无 FPU) 上，我用纯 C 实现了 TinyCNN 的前向推理链路，让单片机可以完成手写数字识别。

核心指标

  • 硬件: STM32F103C8T6 + USB 转 TTL + Python 手写数字画板
  • 模型: PyTorch 训练，2 层卷积 + 1 层全连接
  • 推理耗时: 约 220ms
  • 准确率: MNIST 测试集 >98%
  • 资源占用: Flash < 20KB，RAM < 5KB
